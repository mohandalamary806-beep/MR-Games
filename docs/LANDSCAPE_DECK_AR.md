# واجهة المكتبة الأفقية — MR Games 1.0.0

## الشاشة الرئيسية
- تعمل بوضع العرض الأفقي، مع شعار MR Games وAdd Game والإعدادات في الشريط العلوي.
- منطقة المكتبة اليسرى تعرض الألعاب كرف أفقي قابل للتمرير.
- منطقة الحالة والأداء اليمنى تعرض ملخص الجهاز، ملف الأداء والدقة الافتراضية.
- شريط تنقل سفلي يفتح Home وLibrary وSettings وDesktop.

## أغلفة الألعاب
عند عرض كل اختصار، يحاول التطبيق البحث عن اسمه في Steam Store ثم تحميل صورة الغلاف من Steam CDN. يتم تخزينها مؤقتاً. لو لم توجد نتيجة أو لم يتوفر اتصال، يظهر اختصار بحروف اسم اللعبة وألوان MR Games.

## أزرار التحكم والماوس
ملف التحكم الجديد يوزع عصوي التحكم والاتجاهات وأزرار △ ○ ✕ □ وأزرار L/R على مناطق منفصلة. يتم تحديث ملفات التحكم القديمة مرة واحدة عند أول تشغيل بعد التحديث، بينما يظل أي تعديل يدوي لاحق محفوظاً. مساحة اللمس الفارغة تظل متاحة لحركة مؤشر Windows والنقر.

## حدود هذا التحديث
هذا تحديث للواجهة وتجربة المشغّل على محرك Winlator الحالي. لا يتضمن نقل مصدر WinHub أو تغيير محرك Wine/Box64.
