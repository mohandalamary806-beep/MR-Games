# MR Games — ملفات الأداء

## اكتشاف الجهاز

يعرض التطبيق معلومات الهاتف التي يوفرها Android: الشركة والطراز، اسم SoC إن أتاحه النظام، إجمالي RAM، عدد أنوية CPU، إصدار Android، وهل يعلن النظام عن ميزة Vulkan. قد لا يتيح Android اسم GPU أو ذاكرة VRAM لكل الأجهزة، لذلك لا يخترع التطبيق هذه القيم.

وضع Auto يختار توصية مبدئية من إجمالي RAM وعدد الأنوية وميزة Vulkan. يمكن للمستخدم اختيار أي ملف يدويًا. هذا تصنيف تقريبي وليس اختبار أداء فعليًا.

## الملفات

- **Low-End:** 640×360 + Box64 Performance.
- **Balanced:** 960×544 + Box64 Intermediate.
- **High Quality:** 1280×720 + Box64 Intermediate.
- **Stability:** 854×480 + Box64 Stability.

اختيار الدقة يؤثر على حمل الرسوميات، لكن لا يضمن FPS محددًا. إعدادات الرسوميات داخل اللعبة نفسها قد تحتاج إلى خفض يدوي.

## إعدادات لكل لعبة

افتح Game Library ثم قائمة النقاط الثلاث بجانب اللعبة واختر Settings. يدعم Winlator الأصلي تخزين تعديلات لكل اختصار مثل الدقة، Box64 preset، تعريف الرسوميات، DX wrapper، عناصر Windows Controls وغيرها. هذه الإعدادات الفردية لا تتغير عند تعديل الافتراضيات العامة.

## Desktop والمودات

من MR Games Home افتح Windows Desktop. اختر الحاوية ثم شغّلها للدخول إلى سطح مكتب Windows. من قائمة الحاوية افتح File Manager للوصول إلى ملفات C: والمجلدات المشتركة، ثم انسخ ملفات المودات أو أدوات التعديل التي تتوافق مع اللعبة.

لا يوجد ملف FPS cap عام يضمن حدًا ثابتًا لكل الألعاب في هذا المحرك؛ لذلك لا يعرض MR Games تحكمًا شكليًا لا يطبق فعليًا.

## عداد FPS

تُفعّل اختصارات MR Games عداد FPS الأصلي في Winlator تلقائياً. يظهر العداد في منتصف أعلى الشاشة داخل لوحة زجاجية شبه شفافة صغيرة، بعيداً عن أزرار التحكم. يعرض القياس الفعلي ولا يفرض FPS cap. إذا انتهت عملية اللعبة، تعرض شاشة التشخيص رمز الخروج وتذكّر باستيراد مجلد اللعبة كاملاً وتجربة دقة أقل وملف Stability عند الحاجة.
