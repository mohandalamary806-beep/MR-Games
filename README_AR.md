# MR Games 1.0.0 — مكتبة ألعاب أفقية

MR Games هو مشغّل أندرويد لألعاب Windows، مبني حالياً على محرك Winlator المفتوح المصدر. الإصدار ده يحدّث واجهة المكتبة لتكون بالعرض وبأسلوب Console Deck زجاجي، مع أغلفة ألعاب تلقائية عند توافر تطابق.

## الجديد في الإصدار 1.0.0

- الواجهة الرئيسية أصبحت أفقية (Landscape) بتصميم داكن زجاجي ولمسات سماوية.
- رف أفقي للألعاب يعرض اختصارات Windows الموجودة في حاويات Winlator.
- كل لعبة تظهر في بطاقة بصورة غلاف وعنوان وزر Play.
- التطبيق يحاول العثور على غلاف اللعبة من اسمها في Steam Store، ويحفظ الصورة مؤقتاً على الجهاز بعد تنزيلها.
- لو اللعبة غير موجودة في Steam أو الجهاز غير متصل بالإنترنت، تظهر بطاقة MR Games بديلة باسم اللعبة بدلاً من صورة مكسورة.
- زر Add Game موجود أعلى الواجهة، والضغط على بطاقة اللعبة يشغّل اختصارها الموجود.
- إعدادات الأداء، دقة العرض، حالة الجهاز، المكتبة، الإعدادات وسطح مكتب Windows متاحة من الشاشة الأفقية.
- فرض العرض الأفقي على شاشة المشغّل فقط؛ لم يتم فرضه على شاشة تشغيل اللعبة المنفصلة.
- ملفات تحكم PlayStation الجديدة موزعة بمسافات أوسع، وتسمح باستخدام اللمس كمؤشر ماوس. الملفات القديمة تتحدث مرة واحدة فقط إلى التخطيط الجديد، ثم تظل تعديلات المستخدم محفوظة.

## طريقة ظهور أغلفة الألعاب

البحث عن الأغلفة اختياري ويحتاج اتصال إنترنت. يتم البحث باسم اللعبة في واجهة Steam Store العامة، ثم تحميل صورة `header.jpg` من Steam CDN عند العثور على نتيجة. لا يحتاج البحث إلى حساب Steam أو مفتاح API. التطابق غير مضمون لكل لعبة؛ أسماء ملفات EXE المختصرة أو الألعاب غير الموجودة في Steam قد تظهر لها بطاقة MR Games البديلة.

## نطاق المحرك

**مهم:** هذا التحديث يطوّر واجهة MR Games لتكون قريبة من أسلوب مكتبات WinHub الأفقية، لكنه لا يستبدل محرك التشغيل الحالي بمحرك WinHub. ملف البناء ما زال يجلب مصدر `brunodev85/winlator-app` ويستخدم Wine / Box64 الخاص به. لا يحتوي المشروع على كود WinHub أو أصوله. ترحيل المحرك بالكامل إلى `winhub-emu/winhub` يحتاج إعادة تأسيس مستقلة على مصدره وملفات البناء والترخيص الخاصة به.

## بناء APK عبر GitHub Actions

ملف `.github/workflows/android-apk.yml` يجلب مصدر Winlator، يطبق تعديلات MR Games، ثم يبني `assembleDebug` ويرفع APK كـ Artifact. سكربت التعديل يتحقق من بنية Winlator المطلوبة ويتوقف لو تغيّر المصدر بشكل لا يسمح بالتعديل الآمن.

## ملاحظات مهمة

- للتشغيل المباشر، احتفظ بمجلد اللعبة كاملاً داخل مسار مشترك يراه Winlator مثل Download أو تخزين MR Games المشترك.
- صورة الغلاف لا تؤثر على تشغيل اللعبة؛ إذا فشل البحث تظهر بطاقة بديلة.
- التوافق والأداء يعتمدان على المعالج والرسوميات والتعريفات والذاكرة ومتطلبات كل لعبة.
- تم فحص صياغة سكربت Python، واختبار تعديل Manifest وإصدار التطبيق، وفحص توازن بنية Java. لم يتم بناء APK أو تجربته على هاتف فعلي داخل بيئة العمل الحالية.
